# 墨页 · Markdown 工作空间

一个中文 Markdown 编辑网页，使用原生 HTML、CSS 和 JavaScript，无需安装第三方依赖。

## 启动

推荐使用当前版本 Chrome 或 Edge 打开仓库中的 `墨页.html`。浏览器必须提供 `showOpenFilePicker` 和 `FileSystemFileHandle.createWritable`，打开文档时允许文件读写。如果直接打开文件的环境不提供该 API，可通过下面的 localhost 服务器打开。Safari、Firefox 或不提供该 API 的内置预览器无法写回文件，界面会明确提示，不会回退到缓存保存。

若要修改源码后运行开发版：

需要 Node.js 18 或更新版本。

```sh
npm run dev
```

打开 http://localhost:5173 。修改端口可使用 `PORT=3000 npm run dev`。

## 从终端打开指定 Markdown 文件

需要 Node.js 18 或更新版本，无需安装第三方依赖。在项目目录执行：

```sh
./moye "/绝对路径/我的文档.md"
./moye ./README.md
```

命令会启动或复用后台本地服务，在系统默认浏览器打开墨页并加载指定文件，默认进入文档全屏（保留当前的源码 / 可视化模式），可按 Esc 或右上角全屏按钮退出。支持相对路径、空格、中文路径，符号链接会解析到实际文件；仅接受已有且可读写的 UTF-8 `.md`、`.markdown`、`.txt` 文件，最大 2 MB。网页会显示文件绝对路径，停止输入约 450 ms 后保存到原文件；打开文件本身不会写入。使用该入口时 Safari 也可读写命令指定的文件，不依赖浏览器的文件选择 API。

若要在任意目录使用 `moye`，可在已经加入 PATH 的个人 bin 目录中创建一次软链接。例如本机 `~/.local/bin` 已在 PATH 中：

```sh
ln -s "/Users/azzhu/Documents/ChatGPT/markdown可视化网页/moye" "$HOME/.local/bin/moye"
moye "/绝对路径/我的文档.md"
```

项目移动后需要更新链接。也可直接使用启动脚本的完整路径，或通过 `npm run open -- "文件路径"` 启动。

```sh
moye --no-browser "./我的文档.md"   # 只输出访问地址
moye --help                      # 查看用法
moye --stop                      # 确认网页修改已保存后，停止后台服务
```

服务仅监听 `127.0.0.1`，默认端口 5174；首次启动可用 `MOYE_PORT=5175 moye 文件.md` 指定端口。后续命令复用同一项目已经运行的服务，同一个文件可在多个页面打开，保存时检测版本冲突。后台服务启动后可以关闭终端；停止服务后，网页无法继续保存，需重新运行命令打开原文件。再次启动会更新文件访问凭据，旧标签页需要用新命令输出的地址打开。

命令行入口允许网页读写终端明确打开过的 Markdown 文件，以及只读访问该文件所在目录及子目录中的图片，以文件专属凭据验证每次访问；不提供任意路径文件读取或写入接口。图片不允许使用绝对路径、`..` 跳出目录或通过符号链接访问目录外文件。运行状态和服务凭据保存在项目目录 `.moye-runtime.json`（权限 600，Git 忽略），文件凭据可随历史关联保存到该服务地址下的浏览器 IndexedDB。不同浏览器、`file://` 和本地 HTTP 地址的草稿、设置、历史记录各自独立。

保存采用串行队列、磁盘内容核对和同目录临时文件替换，保留 UTF-8 BOM 与文件权限；临时文件写完后再次核对原文件，遇到外部修改会保留网页草稿并提示冲突。该核对不是跨程序文件锁，仍不应让多个程序同时提交同一文件。

### 文档中的本地图片

通过 `moye` 命令打开 Markdown 时，图片以 Markdown 文件所在目录为基准解析，支持同目录与子目录图片、中文文件名和 URL 编码的文件名。例如：

```markdown
![用户数与平均 RT、RPS 的关系](单台压测_用户数_RT_RPS.png)
![子目录图片](images/结果.png)
![带空格和括号的图片](<images/结果 图(1).png>)
```

支持 PNG、JPEG、GIF、WebP、AVIF、BMP、ICO，单张最大 20 MB。图片读取时核对文件类型；不支持 SVG、本机绝对路径和父目录路径。图片不存在、读取失败或服务停止时，渲染区显示失败提示及原始路径。可视化编辑、自动保存、撤销与重新打开时保留相对路径，不会把服务地址或访问凭据写进 Markdown。

直接打开独立 HTML 或通过网页「打开文档」选择文件时，也可以加载本地图片（需 Chrome 或 Edge 支持目录选择）：

1. 打开 Markdown 文档后，点击文档工具栏右侧的文件夹按钮「图片目录」（仅在存在相对路径图片时显示；窄窗口只显示文件夹图标）。
2. 选择当前 Markdown 文件所在的文件夹，授予只读权限；应用会核对该目录中的文件确实是当前文档，避免关联到其他同名文件。
3. 自动读取该目录及子目录内的图片，不修改图片，也不改变 Markdown 的原文件保存权限。

目录句柄按每篇文档保存在浏览器 IndexedDB 中。从历史记录重新打开时，如果目录读取权限仍有效，会直接加载图片；权限失效时点击「图片目录」重新授权。目录已授权时再点击按钮，可重新选择目录并刷新图片。取消选择或拒绝权限不会影响 Markdown 的编辑与保存。删除历史记录会一并移除该目录关联，不删除原文件或图片。

图片通过浏览器临时 Blob 地址显示，切换文档或移除图片时释放资源，保存到 Markdown 的仍是原始相对路径。不支持目录选择的浏览器可使用 `moye`。网络 HTTP/HTTPS 图片继续按原方式显示。图片语法中的括号不应转义：`![说明]\(图.png)` 会按普通文本处理。

更新本地服务代码后，请先确认页面修改已保存，再执行 `moye --stop` 并重新用 `moye 文件.md` 打开，使用新打开的标签页；仅刷新网页不能更新后台服务。命令会检查已运行服务是否支持图片，旧服务会提示先保存再重启，不会擅自停止服务。图片失败提示也会区分后台版本过旧、文件不存在和格式问题。

## 功能

- Markdown 源码 / 可视化编辑，点击「宽度」右侧的「切换显示模式」按钮，在源码和可视化之间切换，内容实时同步；默认进入可视化模式，旧双栏设置自动改为可视化。
- 标题、粗体、斜体、删除线、链接、图片链接、嵌套列表、引用、代码块、任务清单和表格。
- 可视化区域的图片作为不可编辑的图片元素显示，保留浏览器原生右键菜单。图片加载成功后，可右键选择「复制图片」或「图片另存为」（具体名称由浏览器决定）；适用于已授权目录的本地图片、moye 加载的图片和网络图片。图片路径仍按原 Markdown 保存。
- 可视化模式的代码块右上角提供一键复制图标，复制代码正文（保留缩进和换行，不含围栏或语言名称），成功后显示勾选图标与提示。复制按钮不会进入 Markdown，也不会触发文档修改；本地 HTML 环境在剪贴板 API 不可用时尝试浏览器复制命令。
- 原始文件读写、本地文档打开；侧栏历史记录按最近打开或编辑排序，最多保留 20 篇文档，超过后自动移除最早的记录。
- 每条历史记录右侧可单独删除，移除浏览器草稿和文件句柄关联，不删除原始文件。有未写回修改时先保存，失败则保留记录。
- 确认原文件已不存在（删除或移动）时，历史文件名标红并加删除线，悬停显示原因；记录与缓存仍保留，可手动删除。状态会保存并同步到其他页面，重新读取成功后取消标记。点击历史或当前文件外部检测时会检查；直接打开 HTML 时，对已有读取授权的历史文件在页面打开、切回及页面可见时每 15 秒做一次只读存在性检查，不请求新权限。权限不足、离线和普通读取失败不会误标为删除。moye 的明确缺失错误需更新后的本地服务支持。
- 同一个浏览器用户配置下，直接打开同一份 `墨页.html` 的多个页面共享历史：新增、排序与删除会同步；正常收到浏览器存储事件时立即更新，页面可见时每秒补查一次，切回页面时立即检查。保存按条合并，不再由旧页面整份覆盖。删除和超过 20 条时的移除均保存独立删除标记，旧页面刷新或继续保存也不会恢复这些记录；通过「打开文档」明确重新打开原文件则建立新记录。
- 历史同步只更新列表，不切换或重载其他页面正在编辑的文档；其他页面删除当前记录时，已打开的编辑区和未写回修改继续保留。每个页面还在 sessionStorage 单独备份本页实际修改产生的未写回草稿；从其他页面收到的保存中状态不会被当成本页草稿重复备份。恢复时排除已确认保存或与原保存基线完全相同的旧备份，避免刷新后重复恢复过期的未保存标记。同一文件在多个页面同时修改时，继续使用原文件版本冲突检测。浏览器、用户配置、不同 HTML 文件路径及 HTTP 服务入口之间的存储隔离保持不变。
- 每次进入或刷新网页默认不打开任何文档；历史记录仍保留，点击记录或「打开文档」后才显示内容。
- 打开时通过 File System Access API 获取文件读写授权；停止输入约 450 ms 后自动写回原始文件，只有写入流关闭成功才显示「已保存到原文件」。
- 浏览器 localStorage 按条保存历史记录、额外草稿和界面设置；IndexedDB 保存文件句柄。点击历史记录会重新读取原文件并恢复读写连接，需要时请求授权；读取期间暂时只读。读取失败会明确标注当前显示的是旧草稿，可点击保存状态重试，或使用「打开文档」重新选择文件。
- 从历史记录打开时，无未保存修改则显示磁盘最新内容；有未保存草稿则保留草稿，原文件也有变化时提示冲突。打开历史记录本身不会写入原文件。只有读取权限时可显示最新内容，授权写入后才能编辑。
- 写入使用串行队列，失败时保留未保存状态。写入前核对原文件内容，检测到外部修改时停止覆盖。关闭页面时仍有未写回修改会请求离开确认。
- 已连接的当前文档在页面可见时每 1.5 秒读取检查一次，切回页面或切换文档时立即检查。没有未写回修改时自动刷新源码、渲染区和大纲，尽量保留滚动位置和光标；自己的保存不会触发重复刷新。后台页面暂停轮询，不主动请求授权。
- 检测外部变化和重新打开历史时，按实际内容与保存基线核对：缓存内容没有本地变动时采用磁盘最新内容；网页内容与磁盘完全一致时确认已保存并清除过期冲突。仅有未保存标记不会阻止刷新；只有网页与磁盘确实存在不同的修改时才保留冲突。
- 网页有未保存修改时，外部变化触发冲突并暂停自动保存。点击保存状态可对照、复制两份内容；选择保留草稿继续暂停保存，或明确选择采用原文件内容并放弃网页草稿。读取失败、权限失效、原文件超过 2 MB 时提示并保留当前内容。
- 升级时清理未修改的内置示例和旧回收站记录，保留已修改的示例与实际文档。
- 左侧「打开文档」选择本地 `.md`、`.markdown`、`.txt` 文件（最大 2 MB）。右上角不再提供导入、导出入口。
- 文件选择窗口记住上次打开位置：使用固定的浏览器选择器标识，并在 IndexedDB 单独保存最近选择的文件句柄作为下次起始位置。删除历史记录不重置该位置；清理浏览器数据、移动文件或浏览器限制可能使其恢复默认位置。
- 文档大纲、字数、撤销 / 重做、专注模式、阅读风格设置和移动端布局。可视化滚动时，大纲自动高亮当前章节；图片加载、字号调整和全屏切换后重新计算位置，当前大纲项超出侧栏可见范围时自动滚入可见区域。
- 可视化区域光标位于表格第一行时显示宽度浮动面板：支持 60% / 80% / 100% 预设、手动输入 20–100%，以及恢复默认；百分比相对于正文区域。鼠标移到列之间的边界可左右拖动，保持表格总宽不变，仅调整相邻两列，并尽量保留每列至少 48 px。
- 表格宽度以 `<!-- moye-table: {"width":80,"columns":[25,75]} -->` 专用注释保存在表格的上一行（紧挨表头），表格本身仍为普通 Markdown。`columns` 为各列的比例，空数组表示自动分配。其他编辑器通常隐藏 HTML 注释，但不会应用墨页的宽度设置。调整结束后作为一次修改，支持撤销 / 重做并自动写回原文件；Esc 可取消尚未结束的拖动。
- 右上角「宽度」设置正文最大宽度（480–1400 px，默认 1080 px），或选择铺满；设置会自动保存。正文始终适应可用空间。
- 文档工具栏最右侧提供宽度、模式选择、字号、大纲和文档全屏设置。「Aa」调整字体大小（12–24 px，默认 16 px），源码与渲染区同步应用，标题按比例缩放，并自动记住字号。
- 全屏和非全屏时均可点击「切换显示模式」按钮，在源码和可视化之间切换；进入和退出全屏会保留当前显示模式。双击工具栏中间的空白区域可进入或退出文档全屏，也可使用右上角全屏按钮或 Esc 退出全屏。
- 浏览器标签页标题跟随当前文档文件名，切换文档和打开文件后同步更新。
- 顶部文件信息栏已移除，保存状态显示在侧栏左下角，点击仍可保存、重新授权或查看冲突。文档名在侧栏只读显示，悬停可查看打开时获得的路径信息，不再提供重命名功能。全屏时仍可在编辑器底部查看保存状态并处理冲突；窄屏下可通过工具栏或空页面左上角的菜单按钮打开历史记录。

页面高度自动适应浏览器窗口，页面本身不纵向滚动；长文档在编辑区内部滚动，历史记录和文档大纲也可独立滚动。

## 快捷键

⌘（Windows / Linux 使用 Ctrl）+ B 加粗，I 斜体，S 保存，Z 撤销，Shift + Z 重做。⌘ / Ctrl + K 在编辑区插入链接。⌘ / Ctrl + O 打开文档。

## 内容与限制

授权后修改直接写入所选原始文件，不上传文档。浏览器草稿只是额外备份，不能替代文件保存。清理浏览器数据会移除草稿、历史记录和已记住的句柄。旧版本缓存没有原文件关联，需要重新选择原文件；不会猜测路径或覆盖同名文件。恢复的未写回草稿必须核对后按 ⌘ / Ctrl + S 手动保存。历史名称修改不会重命名磁盘文件。

文件句柄提供对授权文件的访问，无需暴露绝对路径。网页仍无法显示系统完整路径。写入前的外部修改核对与提交不是跨程序文件锁，不支持多个程序同时编辑同一文件。

支持安全的 HTML 文字颜色，例如 `<span style="color: #d32f2f;">+1</span>`。支持十六进制颜色、颜色名称以及逗号分隔的 rgb / rgba / hsl / hsla。可视化编辑和本地自动保存会保留文字颜色，浏览器可能将十六进制颜色规范为等效的 rgb 值。支持 `<strong>`、`<b>` 加粗，以及 span / strong / b 的 `font-weight`（normal、bold、100–900 整百值）。颜色和字重在可视化编辑与保存时保留，其他样式和属性被移除。

当前为常用 Markdown 子集，不是完整 CommonMark / GFM 实现。除上述颜色、字重和加粗标签外，其余原始 HTML 显示为文本；不支持数学公式、脚注或 Mermaid。可视化编辑后会规范化空行和列表符号；仅编辑源码时保留原始源码格式。表格支持编辑单元格，暂不支持动态增删行列。可视化编辑基于浏览器原生 contenteditable，推荐使用当前版本 Chrome / Edge / Safari。

测试：`npm test`。

生成单文件版：`npm run build`。该命令将源码内联到 `墨页.html`，请勿直接编辑生成文件。

### 显示风格设置

点击左下角「设置」选择显示风格：默认（保留原界面）、浅色模式、暖纸书房、青竹护眼、雾蓝书桌、玫瑰信笺、沙丘手记、水墨书卷、午夜静读、石墨专注。原侧栏的浅色模式入口已移入设置。

设置提供配色预览，选择风格后立即应用并关闭设置，在当前浏览器中记住选择（`localStorage` 的 `inkwell.appearance.v1`）。旧版深色偏好首次升级会对应到「午夜静读」。风格会调整页面与文档背景、按钮形状、边框、阴影和部分字体；文档字号、正文宽度、行距保持不变，源码继续使用等宽字体。风格不会写入 Markdown，也不会触发原文件保存。
